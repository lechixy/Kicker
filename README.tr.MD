# Kicker

Kick için açık kaynaklı, bağımsız Android istemcisi. Kurulum ve özellikler için [İngilizce README](README.MD) dosyasına göz atın.

## Katkıda bulunma

Hata bildirimleri, özellik önerileri, çeviriler, erişilebilirlik iyileştirmeleri, belge ve kod katkıları memnuniyetle karşılanır.

- Pull request açmadan önce [katkı rehberini](.github/CONTRIBUTING.md) okuyun.
- Hata bildirmek veya özellik önermek için [issue şablonlarını](https://github.com/lechixy/Kicker/issues/new/choose) kullanın.
- Projeye katılırken [davranış kurallarına](.github/CODE_OF_CONDUCT.md) uyun.
- Güvenlik açığı şüphenizi gizli olarak bildirmek için [güvenlik politikasını](.github/SECURITY.md) izleyin.
